# React Calculator (DCIT 26 – Laboratory 1)

React + Tailwind CSS calculator. Logic is in `src/calculatorReducer.js` (React `useReducer` state),
UI is split into `Calculator`, `Display`, `Button` and `Guide` components.

## Run locally
    npm install
    npm run dev

## Deploy (Vercel)
Push to GitHub, import the repo at vercel.com, keep defaults (Framework: Vite, build `npm run build`, output `dist`).
